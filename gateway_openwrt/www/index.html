💻 Virtual COM Port Quick-Connect (TCP Port 9001)

Connect Spectra 900Tools or PuTTY / RMENU across Mawson Station Ethernet

🐧 Linux Mint Quick-Connect (socat):

socat pty,link=/dev/ttyV0,raw,echo=0 tcp:10.130.1.1:9001 &

Creates /dev/ttyV0. Launch Spectra 900Tools or open minicom -D /dev/ttyV0 -b 57600.

🪟 Windows Laptop Quick-Connect:

Use HW VSP3 or com0com/hub4com:

IP: 10.130.1.1 | Port: 9001 | Virtual COM: COM3

Or PuTTY: Connection type Raw, Host 10.130.1.1, Port 9001.

⌨️ Intercepted Local AT Commands (on Port 9001):

  • AT+STATUS? — Prints RF, battery, SF & sleep diagnostics
  • AT+AWAKE=1|0 — Toggle Stay Awake Maintenance Lock
  • AT+SF=9|11 — Synchronized remote SF switch (60s fallback)
  • AT+SCHED=HH,DUR — Set wake hour (UTC) and duration (min)
